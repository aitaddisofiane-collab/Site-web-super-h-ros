# Les Sentinelles des Alpes

Mini-site vitrine présentant une équipe de super-héros fictifs qui protègent Grenoble et ses montagnes.
Projet réalisé dans le cadre du TP#3 « Création d'un site avec Git & GitHub » (BUT Science des Données).

## Contenu du projet

- `index.html` : page d'accueil (nom de l'équipe, slogan, menu de navigation, présentation générale)
- `heroes.html` : présentation des trois super-héros (nom et description)
- `style.css` : mise en forme du site (couleurs, polices, titres)

## Lancer le site

Ouvrir `index.html` dans un navigateur.
